# Kamera-Profile

Auf dem `messstand`-Branch gibt es genau ein aktiv gepflegtes Kamera-Profil:

- `ids_u3_3800cp_hq.yaml`

Es wird standardmaessig vom Launch
`ros2 launch promoc_bringup optical_measurement_system.launch.py`
ueber `camera_type:=ids_u3_3800cp_hq` geladen.

Die allgemeine Beschreibung der Messstand-Konfiguration liegt im Root-README
und in [`../README.md`](../README.md).
