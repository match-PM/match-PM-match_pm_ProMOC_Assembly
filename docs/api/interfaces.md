# API: Interfaces

## Linear Axis Services
- `MoveAbsolute`: Absolutpositionierung
- `GetPosition`: Position abfragen
- `Home`: Referenzfahrt
- `LinearAxisInfo`: Statusnachricht

## Planar Motor Services
- `MoveTo`: 2D-Positionierung
- `GetPosition`: 2D-Position abfragen
- `Home`: Referenzfahrt
- `PlanarMotorInfo`: Statusnachricht

## Nachrichten- und Service-Definitionen
- Definiert in `promoc_assembly_interfaces/msg/` und `promoc_assembly_interfaces/srv/`
