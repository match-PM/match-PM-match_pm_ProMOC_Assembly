# Glossary

- **ROS2**: Robot Operating System 2, Middleware für Robotik
- **LTS300**: Thorlabs Linear Stage, Präzisionsachse
- **PMCLib**: Bibliothek für Planar Motor Steuerung
- **URDF**: Unified Robot Description Format
- **Xacro**: XML Macro Language für URDF
- **Gazebo**: Simulationsumgebung für Robotik
- **colcon**: Build-Tool für ROS2
- **Service**: ROS2-Kommunikationsmechanismus für Anfragen
- **Node**: Ausführbare Einheit in ROS2
- **Topic**: Publish/Subscribe-Kommunikation in ROS2
