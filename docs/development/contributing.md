# Contributing

## Wie du beitragen kannst

- Fehler melden: GitHub Issues nutzen
- Feature-Requests: GitHub Discussions oder Issues
- Pull Requests: Fork, Branch, PR
- Code Style: PEP8, ROS2 Python Style Guide
- Tests: Neue Features mit Tests abdecken

## Entwicklungs-Workflow

1. Fork & Branch erstellen
2. Änderungen vornehmen
3. Tests ausführen
4. Pull Request stellen

## Hinweise
- Siehe `test/`-Verzeichnis für Beispiele
- Dokumentation zu neuen Features ergänzen
