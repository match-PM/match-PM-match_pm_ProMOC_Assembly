🚀 Schnellstart

Führe diese Befehle aus, um das System zu starten:

# 1. System installieren (einmalig) cd setup/ ./install_all.sh # 2. Workspace sourcen cd .. source install/setup.bash # 3. Simulation starten ros2 launch promoc_bringup dual_lts300_gazebo.launch.py

📁 Projekt-Struktur

ProMOC_Assembly/ ├── linear_axis_nodes/ # Thorlabs LTS300 Steuerung │ ├── drivers/ # Hardware-Treiber (Real/Sim/Mock) │ └── lts300_service_node.py # ROS2 Service Node ├── planar_motor_nodes/ # Planar Motor Steuerung │ ├── mover_service_node.py # Hauptservice │ ├── pmclib_loader.py # Smart PMCLib Loading │ └── mock_pmclib.py # Mock-Implementation ├── promoc_assembly_interfaces/ # Custom ROS2 Messages/Services ├── promoc_bringup/ # Launch-Files und Konfiguration │ ├── launch/ # Gazebo-Launch-Files │ ├── config/ # Controller-Konfigurationen │ └── urdf/ # Modulare Robot-Beschreibungen ├── setup/ # Installation und Validation │ ├── install_all.sh # Master-Installer │ └── validate_setup_enhanced.sh # System-Validation ├── docs/ # Diese Dokumentation └── local_libs/ # Proprietary Libraries (PMCLib)

🎮 Verwendung

System-Validation

# Vollständige System-Prüfung cd setup/ ./validate_setup_enhanced.sh # Zeigt detaillierten Report in VALIDATION_REPORT.md

Simulation starten

# Workspace sourcen source install/setup.bash # Dual LTS300 System ros2 launch promoc_bringup dual_lts300_gazebo.launch.py # Einzelachsen-Test ros2 launch promoc_bringup test_single_lts300.launch.py test_axis:=x

Bewegungskommandos

# X-Achse zu 50mm bewegen ros2 service call /promoc_assembly/x_axis/move_absolute \ promoc_assembly_interfaces/srv/linear_axis/MoveAbsolute \ "{target_position: 0.05, velocity: 0.01}" # Position abfragen ros2 service call /promoc_assembly/x_axis/get_position \ promoc_assembly_interfaces/srv/linear_axis/GetPosition # Achse homen ros2 service call /promoc_assembly/x_axis/home \ promoc_assembly_interfaces/srv/linear_axis/Home

Status überwachen

# Verfügbare Topics anzeigen ros2 topic list # Achsen-Status live verfolgen ros2 topic echo /promoc_assembly/x_axis/linear_axis_info

📋 Verfügbare Dokumentation

Nach der Installation von Sphinx können Sie die vollständige Dokumentation generieren:

# Sphinx installieren (für Ubuntu 24.04) sudo apt install python3-sphinx python3-sphinx-rtd-theme # Oder mit pip (--break-system-packages erforderlich) pip install --break-system-packages sphinx sphinx-rtd-theme myst-parser # Dokumentation generieren cd docs/ make html # In Browser öffnen make view

🆘 Troubleshooting

  • ROS2 nicht gefunden: source /opt/ros/humble/setup.bash
  • Package nicht gefunden: source install/setup.bash
  • Build-Fehler: rm -rf build install log && cd setup && ./install_all.sh
  • Permissions: chmod +x setup/*.sh
  • Dependencies: cd setup && ./validate_setup_enhanced.sh
